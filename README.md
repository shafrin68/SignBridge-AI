
# SignBridge AI 🤟

## About
SignBridge AI is an AI-based hand detection project designed to support communication for people with hearing and speech disabilities.

## Features
- Upload hand gesture images
- AI-based hand detection
- Hand landmark detection
- Visual detection results

## Technologies Used
- Python
- Streamlit
- MediaPipe
- OpenCV
- NumPy

## Installation
pip install -r requirements.txt

## Run
streamlit run app.py
